    Contas de cada pessoa

    Cada pessoa deve criar sua própria conta com um e-mail diferente. Gavetas, itens e arquivos ficam separados por conta.

    Entre com seu e-mail para abrir somente o armário dessa conta. Para outra pessoa, use outro e-mail e cadastre uma conta separada.

    Abra o link que enviamos ao seu e-mail para definir uma nova senha.

    A cópia é opcional. Só copie se os dados salvos neste aparelho pertencem a esta pessoa; eles não são transferidos automaticamente entre contas.
